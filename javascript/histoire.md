# L'histoire de JavaScript

JavaScript est un langage de programmation créé en **1995** par Brendan Eich, alors qu'il travaillait chez Netscape Communications.

Le développement du langage n'a duré qu'environ **10 jours**. Son objectif était de rendre les pages web interactives, alors que les sites étaient jusque-là essentiellement composés de contenu statique en HTML.

À l'origine, le langage s'appelait **Mocha**. Il a ensuite été renommé **LiveScript**, avant d'adopter le nom **JavaScript** peu avant sa sortie officielle.

Le nom *JavaScript* a été choisi pour profiter de la popularité du langage **Java**, très en vogue à l'époque. Malgré son nom, JavaScript n'est pas une version simplifiée de Java : les deux langages ont été développés indépendamment et reposent sur des concepts très différents.

En **1997**, JavaScript est standardisé sous le nom **ECMAScript** par l'organisation **Ecma International**. Cette standardisation permet aux différents navigateurs d'implémenter un comportement commun et compatible.

Au fil des années, JavaScript a connu de nombreuses évolutions. L'une des plus importantes est **ECMAScript 2015 (ES6)**, qui introduit de nombreuses fonctionnalités modernes comme :

- `let` et `const`
- Les fonctions fléchées (`=>`)
- Les classes
- Les modules (`import` / `export`)
- Les Promises
- Les template literals
- Le destructuring
- Et bien d'autres fonctionnalités qui facilitent le développement moderne.

Aujourd'hui, JavaScript est l'un des langages de programmation les plus utilisés au monde. Il permet de développer :

- Des sites web interactifs
- Des applications web complètes
- Des serveurs avec Node.js
- Des applications mobiles
- Des applications de bureau
- Des jeux vidéo
- Des objets connectés (IoT)

> **À retenir :** Malgré son nom, JavaScript n'a pratiquement aucun lien technique avec Java. Il s'agit de deux langages distincts ayant des objectifs et un fonctionnement différents.
